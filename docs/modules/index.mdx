# Runtime modules

Each page here covers one Cloudflare Workers capability on OpenOrange: a
binding, an event handler, or the runtime globals. To see what each binding of
your project runs on and what it needs, run `orange doctor`, or start with
[Bindings](./bindings.mdx).

A binding page opens with a status summary and a quickstart. Its full
reference (compatibility, limits, differences from Cloudflare, and test
evidence) is in the collapsed AI context at the end of the page. There, a
feature is **Supported** when unchanged code runs, **Partial** when some
documented APIs throw or act differently in ways that common code can hit, and
**Not supported** when its calls throw.
