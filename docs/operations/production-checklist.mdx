# Production checklist

Check these before your app serves production traffic. Rivet's own checklists cover the rest.

## Quickstart

<Steps>

<Step title="Lock down tokens and secrets">

CI deploys with a cluster token in `RIVET_CLOUD_TOKEN` that has only the scopes it needs. See
[Sign in](../deploy#sign-in). Pass secrets with `--secrets-file` or `--secret`, never in `vars`,
which are part of the image.

</Step>

<Step title="Run at least two nodes">

Objects then have a runner to wake on during a rollout.

```sh
orange deploy --node-count 2
```

</Step>

<Step title="Deploy next to your database">

See [Regions](./regions).

</Step>

<Step title="Turn on monitoring">

Send traces, metrics, and logs to your tools. See [Monitoring](./monitoring).

</Step>

<Step title="Keep each build ID">

Each deploy prints one. To roll back, deploy an earlier build:

```sh
orange deploy --cluster <cluster> --pool <pool> --build <build-id>
```

</Step>

</Steps>

## Self-host

Pass `RIVET_ENDPOINT` as a secret, raise `RIVET_NODE_VERSION` on every deploy, and upgrade the
Rivet Engine before OpenOrange.

<AiContext summary="Why each check matters, and the rest of the list">

#### Tokens and secrets

- Clients that must not call your Durable Objects directly get Rivet tokens without an
  `actor_gateway` grant. See [Who can call an object](../modules/durable-objects#who-can-call-an-object).
- Self-hosted, `RIVET_ENDPOINT` holds a token, which is why it goes to the container as a secret.

#### Scaling

- Pick the size of the pool's nodes with `--machine-type`.
- WebSocket clients reconnect after a random wait when a socket closes with `1012`. A deploy
  closes the sockets of each runner it replaces. See
  [Runner churn closes the sockets](../modules/durable-objects#runner-churn-closes-the-sockets).

#### Self-hosted runners

- Each deploy sets `RIVET_NODE_VERSION` to a higher number than the last one, so new and waking
  objects start only on the new runners. Without it, RivetKit logs an error at startup. Rivet
  Cloud sets it for you.
- Upgrade the Rivet Engine before you upgrade OpenOrange. A new OpenOrange can bring a new
  RivetKit, which can need a newer Engine.

</AiContext>
